⚠️

Reading this table honestly

The scores are extremely high because the dataset still contains Salary Package — a value a student only has after being placed. A model can therefore "cheat" by reading it. This is called target leakage, and it inflates every placement score in this table. The Decision Tree and Random Forest were both trained with that column present, so the fair reading is: the ranking is still useful, the percentages are optimistic. Re-training without Salary Package (and without IsAnomaly) would give a realistic score.

🧭

Two models are deliberately left out of the ranking

AdaBoost reached 0.9996 accuracy and F1, but its recorded metrics are for a different target — the 3-class CGPA_Tier (High / Mid / Low), not placement — and its feature list also contains PlacementStatus itself. Binary Logistic Regression saved its predictions with an inconsistent label encoding (-1/0 actual vs 0/1 predicted), so no honest score can be computed from the saved file. Both are still shown in the gallery below, untouched.

Predicting the placement number

A different task: instead of yes/no, these models predict PlacementStatus as a number (0 or 1) and are judged with error metrics. Table 3 · Unsupervised

Clustering and dimensionality reduction

These models have no target label to learn from, so they cannot predict placement. They are used to group students into profiles (Hierarchical, DBSCAN, K-Means) and to compress and visualise the {{ total_columns }} columns as a small number of new dimensions (PCA, t-SNE). Silhouette score ranges from -1 to 1 (higher is better). Calinski-Harabasz and Davies-Bouldin compare cluster quality between methods. Silhouette values in the single digits are normal for student data, where profiles overlap a lot. DBSCAN's eps = 0.80 and min_samples = 10 decide how dense a region must be to count as a cluster.
