About the project

What is the Placement Prediction System?

A student-employability analysis and prediction system built with Python, Pandas and scikit-learn. It studies 50,000 student records and learns which academic, skill and background factors lead to a placement.

🎓

The idea

Placement outcomes depend on a mix of academics (CGPA, semester grades, attendance), skills (aptitude, coding, soft skills) and background (college tier, stream, hostel, backlogs). This project puts all of that into one dataset and asks a single question: will this student be placed?

🎯

The goals

Understand the data, build a clean and reusable preprocessing pipeline, compare several models fairly, and end with a working prediction page where a student profile can be entered and scored live.

🧪

How it is built

Twenty models and methods — linear and logistic regression, regularisation, decision trees, random forest, AdaBoost, clustering, PCA and t-SNE — all trained on the same cleaned data, with every chart and metric kept in per-module output folders.

🔍

How to read the results

The recorded scores are very high, and the Models page explains why (one field, Salary Package, is only known after a student is placed). The honest reading — and the recommended next step — is shown clearly next to every table.

🐍 Python 🐼 Pandas 🧠 scikit-learn 🔥 Flask 📊 Matplotlib · Seaborn 🔢 NumPy
