The outcome

The final preprocessed file

Inside final_preprocess_M2.csv

This is the one file the whole project agrees on. The same {{ "{:,}".format(total_rows) }} students and the same {{ total_columns }} columns as the raw data — nothing added, nothing lost — only made clean, numeric and fair.

  • Every gap closed — the {{ "{:,}".format(missing_cells) }} missing values across 5 columns are filled with the mean / median.
  • Every text column turned into numbers, so the models can actually read them.
  • Numeric columns scaled (min-max / standardization / normalization) so no single feature dominates.
  • Checked before saving — 0 missing values, 0 duplicate rows, 100% numeric.
  • Rebuilt by one script — final_preprocess_M2.py regenerates it from raw on demand.
